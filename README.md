# Facebook Clone Website

This project is a **Facebook Clone Website** that I created while following a Git and GitHub tutorial. The main purpose of this project was to practice my web development skills and learn how to manage projects using Git and GitHub.

## 📌 About the Project

The Facebook Clone Website is a practice project inspired by Facebook's user interface and design. It helped me understand how website layouts are created and how different web development concepts work together to build a website.

I developed this project as part of my learning journey and used it to gain practical experience while following the tutorial.

## 🎯 Objectives

* To practice website development.
* To understand the basic structure of a website.
* To improve my coding and problem-solving skills.
* To learn how to use Git for version control.
* To practice uploading and managing projects on GitHub.
* To understand how repositories, commits, and branches work.

## 🛠️ Technologies Used

* **HTML** – For structuring the website.
* **CSS** – For styling and designing the user interface.
* **Git** – For version control and tracking changes.
* **GitHub** – For hosting and managing the project repository.

## 📚 What I Learned

While working on this project, I gained practical experience with Git and GitHub, including:

* Creating and managing a Git repository.
* Tracking changes in project files.
* Making commits to save changes.
* Uploading a local project to GitHub.
* Understanding the importance of version control.
* Organizing and maintaining project files.
